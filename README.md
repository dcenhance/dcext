## Add the repository

### Development — this branch

```text
https://raw.githubusercontent.com/dcenhance/dcext/dev/repo.json
```

### Stable — recommended for normal use

```text
https://raw.githubusercontent.com/dcenhance/dcext/main/repo.json
```

In CloudStream, open **Settings → Extensions → Add Repository**, paste one URL, and confirm.

> This channel provides **CSM Dev** testing builds. CSM Stable and CSM Dev use the same internal plugin identity, so choose one channel and do not install both simultaneously. Returning from a newer Dev build to an older Stable build may require uninstalling CSM first.

## Channels

- **Development (`dev`)** — preview CSM builds for testing. Features may change or break.
- **Stable (`main`)** — tested public CSM releases.

## Included extensions

- **CSM Dev** — development builds of CloudStream customization, player tools, Discord integration, downloads, profiles, navigation, appearance, and Android TV support.
- The remaining provider entries continue to use their stable releases unless their manifest explicitly says otherwise.

The repository manifests are the authoritative source for current versions and availability.

## Requirements

- CloudStream 4.x
- Android 5.0 or newer; individual features can require a newer Android version
